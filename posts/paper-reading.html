보안 세미나 12강으로 넓힌 연구 지도

암호부터 물리계층, SecOps, AI Agent, Web3까지 이어진 세미나를 정리하고 ARM PAC 분석으로 관심 분야를 구체화했습니다.

1. 암호와 시스템 보안의 연결

하계 보안 세미나 1강부터 3강까지는 암호가 어떤 가정 위에 서 있는지, 양자 컴퓨팅이 기존 공개키 암호에 어떤 영향을 주는지, SIS·LWE 문제에서 Kyber와 ML-KEM·ML-DSA가 어떻게 이어지는지를 정리했습니다.

4강부터 6강까지는 자동차 보안, 임베디드·자동차 시큐어 코딩 표준, 국가 보안적합성 검증 체계를 다뤘습니다. 알고리즘이 안전해도 실제 제품의 코드와 개발 절차, 검증 체계가 함께 받쳐주지 않으면 보안이 완성되지 않는다는 흐름을 확인했습니다.

2. 통신과 보안 운영으로 범위 넓히기

7강과 8강에서는 무선 채널 특성을 이용하는 물리계층 보안과 제한된 전력 안에서 비밀 전송률을 높이는 최적화 문제를 공부했습니다. 9강과 10강에서는 SIEM·SOAR·EDR·XDR·CTI, Event와 Alert, 오탐과 미탐, 사고 대응 흐름을 정리했습니다.

11강과 12강은 도구를 호출해 행동하는 AI Agent의 보안 문제와 중앙기관 없이 거래를 검증하는 Web3·블록체인 구조를 다뤘습니다. 서로 다른 주제처럼 보였지만 신뢰 경계, 관찰 가능한 증거, 실패 시 대응이라는 공통 질문으로 연결할 수 있었습니다.

3. ARM PAC 보호기법 분석

별도의 분석 글에서는 ARMv8.3-A의 Pointer Authentication을 살펴봤습니다. 반환 주소나 함수 포인터에 인증 코드를 결합해 메모리 손상 공격으로 포인터가 바뀌었는지 확인하고, ROP·JOP 같은 제어 흐름 탈취를 어렵게 만드는 원리를 정리했습니다.

기존의 DEP/NX, ASLR, Stack Canary와 비교하며 PAC가 무엇을 보완하는지, 어떤 위협 모델을 전제로 하는지 나누어 설명했습니다. 보호기법을 이름으로 외우기보다 공격자가 가진 능력과 방어가 보장하는 범위를 함께 보는 연습이 됐습니다.

4. 세미나 정리와 논문 리뷰는 다르다

현재 공개 기록에서 확인되는 것은 세미나 12강의 학습 노트와 기술 분석 글입니다. 직접 작성한 논문, 학술대회 발표, 특정 논문의 실험을 재현한 정식 리뷰는 아직 확인되지 않습니다.

따라서 이 활동의 성과는 폭넓은 연구 주제를 탐색하고 질문의 지도를 만든 것입니다. 다음에는 관심 분야를 ARM 시스템 보안과 AI Agent 보안으로 좁혀, 논문의 문제·방법·실험·한계를 같은 형식으로 비교하고 공개 코드가 있는 연구는 재현 결과까지 남길 계획입니다.
