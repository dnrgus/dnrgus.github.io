CTF Solver Agent 개발

여러 LLM 솔버가 각각 격리된 환경에서 문제를 풀고 관찰 결과를 공유하는 도구를 구성했다. 이 작업에서 가장 신경 쓴 부분은 성공 판정이었다.

실행 구조

기존 오픈소스 두 프로젝트를 결합하고 솔버별 Docker 환경, 반복 호출 제한, 비용·시간 제한을 마련했다. 솔버가 찾은 문자열은 우선 후보로만 기록한다.

검증 기준

새 샌드박스에서 풀이가 재현되거나 공식 검증기가 플래그를 수락해야 해결로 표시하도록 상태를 나눴다. 우연히 맞는 형태의 문자열과 실제로 풀린 문제를 구분하기 위한 선택이었다.
