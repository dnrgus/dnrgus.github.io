Windows Notepad CVE 분석

Windows Notepad의 마크다운 렌더링 기능과 관련된 CVE-2026-20841을 분석해 입력과 실행 경로를 정리했다.

확인한 내용

어떤 기능이 문제의 출발점인지, 공격에 필요한 조건과 영향, 완화 방법을 나누어 살폈다. 사용자가 파일을 여는 흐름까지 포함해 설명하려고 했다.

기록의 성격

새 취약점 발견 보고서가 아닌 공개 CVE 분석 글이다. 제품 버전과 패치 상태는 사용 환경에 따라 달라질 수 있어 원문과 공식 안내를 함께 확인해야 한다.
