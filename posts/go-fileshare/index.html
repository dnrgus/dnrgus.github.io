Go 파일 공유 서비스 개발

Go 표준 라이브러리로 파일 업로드와 공유 기능을 만들었다. 업로드가 되는지뿐 아니라, 어떤 파일을 받고 언제 지울지까지 함께 다뤘다.

기능과 입력 검증

웹 화면과 curl에서 업로드할 수 있도록 하고 공유 링크, 기본 24시간 만료, Range 다운로드, 삭제 키를 구현했다. 경로·확장자·MIME을 확인하고 요청 속도와 저장 용량에도 제한을 뒀다.

다시 확인한 방법

단위·통합 테스트와 curl로 업로드부터 다운로드까지 확인하는 시험를 실행했다. 방어 코드를 일부러 제거했을 때 테스트가 실패하는지도 확인했다. README에는 실행 방법과 위협 모델, 알려진 한계를 적어 다른 사람이 같은 조건에서 점검할 수 있도록 했다.
