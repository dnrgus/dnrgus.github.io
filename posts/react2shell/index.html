React2Shell 취약점 분석

React Server Components의 역직렬화 문제로 공개된 CVE-2025-55182를 읽고, 취약한 입력이 어떤 경로로 위험한 동작에 이르는지 정리했다.

분석 관점

영향을 받는 기능과 공격 조건, 영향 범위, 완화 방법을 구분해 설명했다. CVSS 점수만 옮기기보다 입력 처리 흐름을 이해하는 데 시간을 썼다.

성과의 범위

공개된 CVE를 분석한 글이다. 취약점을 최초 발견하거나 실제 버그바운티 프로그램에 제출한 기록으로 적지 않았다.
