프로젝트 README 정리

GitHub 저장소의 README를 실행 안내와 검증 기록으로 다듬었다. 처음 보는 사람이 프로젝트를 실행하고 결과를 확인할 수 있는 문서를 목표로 했다.

담은 내용

필요한 환경, 실행 명령, 디렉터리 구조, 테스트 방법, 제한 사항을 프로젝트 문서에 적었다. UNKNOWN Beginner CTF에는 Docker Compose 실행 절차를, CTF Solver에는 검증 상태와 브랜치 차이를 설명했다.

남은 기준

README에 적힌 명령이 실제로 동작하는지 새 환경에서 다시 확인하는 작업이 필요하다. 소개 문구보다 재현 가능한 절차를 앞에 두려 한다.
