GitHub Pages로 정적 블로그 시작하기

저장소의 파일이 웹사이트가 되는 과정을 이해하고, 첫 페이지를 배포하는 순서를 정리했습니다.

GitHub Pages란?

GitHub Pages는 GitHub 저장소의 HTML, CSS, JavaScript 파일을 공개 웹사이트로 게시하는 정적 호스팅 서비스입니다. 계정 이름이 dnrgus라면 dnrgus.github.io 저장소의 사이트 주소는 https://dnrgus.github.io/가 됩니다. 서버에서 실행되는 데이터베이스나 비밀 키가 필요한 기능은 별도의 서비스가 필요합니다.

게시 순서

저장소 루트에 index.html을 만들고, Settings → Pages에서 main 브랜치의 /(root)를 게시 소스로 선택합니다. 변경 사항을 커밋하면 GitHub Actions의 Pages 배포 작업이 실행됩니다. Actions에서 성공 여부를 확인한 뒤 사이트 주소를 새로고침합니다.

운영 메모

글을 추가할 때는 파일 이름과 링크를 함께 점검하고, 이미지에는 대체 텍스트를 넣습니다. 비밀번호·토큰·개인정보는 공개 저장소에 올리지 않습니다. 배포가 보이지 않으면 Actions 기록과 Pages 설정의 주소를 먼저 확인합니다.
