Dreamhack 시스템 기초 학습

Linux 메모리 배치와 x86-64 어셈블리를 공부하고 퀴즈 풀이를 글로 남겼다. 워게임 풀이에 필요한 용어를 코드와 연결해 보는 단계였다.

학습 내용

Linux Memory Layout 2편과 x86 Assembly 5편에서 Code·Data·BSS·Stack·Heap, 레지스터와 피연산자, 주요 명령을 정리했다.

확인 방법

용어를 외우는 데서 멈추지 않고 변수의 위치와 명령 실행 뒤 레지스터 값이 바뀌는 이유를 문장으로 설명했다. 이 일곱 편은 기초 학습 기록이며, 별도의 대회 성적을 의미하지 않는다.
