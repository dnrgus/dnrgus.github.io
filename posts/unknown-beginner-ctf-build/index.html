입문용 CTF 플랫폼 만들기

CTF를 처음 접하는 사람이 부담 없이 들어올 수 있도록 입문용 대회 플랫폼을 만들었다. 문제 난이도만큼 화면 구성에도 신경을 썼다.

왜 입문용을 따로 만들었나

Dreamhack이나 일반 워게임을 많이 풀어 본 사람은 문제 자체보다 플랫폼 사용법이 더 낯설다는 이야기를 주변에서 자주 들었다. 입문자는 어디서 시작해야 할지, 플래그를 어떻게 제출하는지부터 막힌다. 그래서 난이도를 낮추는 것과 함께 플랫폼 흐름을 단순하게 만드는 것을 목표로 했다.

구성

CTFd를 기반으로 만들었고, 문제 화면과 점수판 화면을 UNKNOWN 전용 다크 테마로 새로 꾸몄다. 카테고리는 Web, Pwn, Reversing, Crypto, OSINT, Misc 여섯 개로 나눴다. 플래그 형식은 UNKNOWN{...}으로 통일했다.

점수판은 두 가지로 만들었다. 전체 순위를 보여 주는 화면은 순위, 팀, 점수, 푼 문제 수만 보여 준다. 상세 화면은 팀과 문제가 교차하는 표를 보여 주고, 카테고리별로 묶어서 문제마다 누가 먼저 풀었는지 First Blood 표시를 붙였다.

돌아보며

입문자용 플랫폼을 만들면서 가장 많이 고민한 것은 쉬운 문제를 쉽게 보이게 하는 방법이었다. 문제를 쉽게 만드는 것보다 쉬운 문제가 어디 있는지 찾기 쉽게 하는 쪽이 더 중요했다. 이 경험은 이후 웹 서비스를 만들 때도 화면 흐름을 먼저 보는 습관으로 이어졌다.
