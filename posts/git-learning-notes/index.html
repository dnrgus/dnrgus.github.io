Git 학습 기록 7편

기록 방식

명령어 목록을 외우기보다 작업 디렉터리, 스테이징, 커밋, 원격 저장소가 어떻게 이어지는지 순서대로 적었다.

현재의 위치

초기 글은 학습 노트의 성격이 강하다. 이후에는 같은 주제라도 실행 환경과 확인한 결과를 더 분명히 적으려 한다.
