React2Shell(CVE-2025-55182) 분석

React Server Components에서 발견된 CVSS 10.0 원격 코드 실행 취약점을 읽고 정리했다. 공격 입력이 어떤 경로로 위험한 동작까지 가는지를 따라가 보는 것이 목표였다.

요약

CVE-2025-55182는 React2Shell이라는 이름으로도 불린다. React Server Components의 Flight 프로토콜이 서버로 들어온 요청을 역직렬화하는 과정에서 검증이 부족해 생긴 문제다. 인증 없이도 서버에서 임의 JavaScript를 실행할 수 있어서 CVSS 10.0을 받았다.

영향 범위는 react-server-dom-webpack, react-server-dom-parcel, react-server-dom-turbopack 같은 패키지와 이를 쓰는 프레임워크들이다. Next.js를 비롯해 RSC를 쓰는 생태계 대부분이 해당된다.

배경: Flight 프로토콜

RSC는 컴포넌트 트리의 일부를 서버에서 그려서 클라이언트로 보내는 구조다. 클라이언트 번들을 줄이는 대신 데이터 처리를 서버에 맡긴다. 이 구조를 가능하게 하는 것이 Flight 프로토콜이다. 클라이언트가 서버 함수를 호출하면 요청 본문을 서버가 역직렬화해서 실제 함수 호출로 바꾼다. 문제는 바로 이 역직렬화 단계에서 생겼다.

타임라인과 생각

글에 정리된 타임라인을 보면 2025년 11월 29일에 Meta Bug Bounty를 통해 제보가 들어왔고, 다음 날 Meta 보안팀이 확인했다. 패치는 12월 3일에 공식 배포되었다. 제보부터 패치까지 일주일 남짓이었다는 점이 인상 깊었다.

이 취약점을 읽으면서 입력을 믿지 않는 방식이 얼마나 중요한지 다시 느꼈다. 역직렬화는 데이터를 객체로 바꾸는 편리한 기능이지만, 그 편리함이 곧 공격 표면이 된다.
