LLM 보안 테스트 자동화

허가된 LLM·RAG·AI Agent·웹 서비스를 반복해서 점검하기 위한 자동화 프로젝트를 진행했다. 실행 전에 대상과 프로그램 정책을 확인하는 구조부터 만들었다.

범위 확인

Scope와 Program Policy를 실행 조건으로 두고 허용되지 않은 도메인, 기법, 요청량을 차단하도록 설계했다. 이후 테스트 선택, 실행, 판정, 재현, 증거 정리, 보고서 생성을 연결했다.

결과의 한계

발견 후보는 반복 실행과 정상 입력과 비교하는 대조 시험로 다시 확인하고 민감한 값은 보고서에서 가리도록 했다. 이 저장소는 테스트 도구 개발의 근거다. 실제 버그바운티 제보나 채택 실적을 뜻하지는 않는다.
